# Rejuyan Hossain Shawon — Engineering Portfolio

React + TypeScript + Vite portfolio featuring a real portrait, experience, research, and three engineering case-study pages.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Case study routes

- `/projects/contextai`
- `/projects/fintrack`
- `/projects/phonepulse-ai`

For static hosting, configure a rewrite of non-file URLs to `/index.html` so direct case-study links work. Vercel and Netlify support SPA fallback rewrites.

## Before publishing

- Replace illustrative UI project art with **real screenshots** from the deployed apps.
- Verify live demos and GitHub links.
- Review the résumé PDF included in `public/` for accuracy.
- Confirm research publication links and add them when available.
- Add your own domain, Open Graph preview and analytics only if desired.
- All project testing and limitations are described based on supplied READMEs, not independently verified.
